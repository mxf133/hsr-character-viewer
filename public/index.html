权重 三大类：关卡权重决定 哪些副本算数（角色总榜与抽卡方案都吃它，调成 0 = 这个副本不进榜）； 抽卡权重决定角色总榜与抽卡方案里强度 / 性价比 / 泛用性 各占多少（强度越高越推行动值低、投入高的强队， 性价比越高越推你还要补得越少的队伍）； 版本权重决定每个副本窗口里从最新往前 N 个版本各占多少 （越旧被稀释得越厉害，某一版设 0 = 那一版不进窗口；默认 6 版， 用加一版 / 删一版改窗口长度，1~12 版）。 三组都只有相对大小有意义，改任一组都会重算总榜。

角色总榜 角色 / 星魂 / 光锥混排 · 只看黑塔网投稿数据

看什么 这个榜完全不看你的角色池：它只统计黑塔网上别人投稿的配队， 你抽到没抽到都不影响名次。 怎么算 每个副本先只保留判据最好的一档与次好的一档 （混沌回忆/虚构叙事是 0T / ≤2T、末日幻影是 积分 4000 / ≥3700、异相仲裁·绝境王棋关是行动值 <300 / <500）， 这批投稿全部进池（v4.6.78 起不再只圈最便宜的 25%）， 最后看每个单位在这批里出现的占比—— 占比越高说明它越常在能出分的阵容里出现。

切档位 下面的 E0 / E1 / E2 / E6 是把这一份榜拆成四个星魂档： 每一档各自比较，一个角色在每个档位都可能有自己的一行 （取它抽到这一档时最强的那个整包）。 不会消失 所以「最佳成绩在 E2」的角色，切到 E0 也能看到它 E0 档的分数与名次 —— 不会因为别的档位分更高就不见了。

抽卡方案

是什么 一条可以照着走的补金路线：先看你已有几位核心角色， 再看下一步最适合补什么。 队伍来源 候选来自逐档榜 ∪ 角色总榜 ∪ 行动值前沿（每个副本行动值最好的 8 支）， 同一支队伍只留一条。 分数怎么算 补金推荐分 = 队伍强度 × 抽卡权重 + 队伍性价比 × 抽卡权重 + 队伍泛用性 × 抽卡权重， 三项一个是「这支队打得多好」、一个是「你还要补几金」、一个是「好不好换人」，各管一头。 队伍强度 取角色总榜那一列的「角色强度」分（绝对 0~100，与总榜同一个数）—— 每个副本取最近版本那一次成绩的行动值、按关卡权重加权，再按投入档位补分， 所以行动值越低越高、投入越高越高（E6S5 > E6S1 > E2S1 > E0S0）， 与金数无关。 队伍性价比 只看你自己还要补几金：补得越少分越高，正好补到「候选池封顶值」= 0 分， 超过就转负分（最低 −100）—— 所以「要补十几金」的队伍会被真的压下去， 而不是和更贵的队一起并排停在 0 分（指数 1.8 让尾部掉得更快，补 1~2 金的几乎不受影响）。 每张卡 都带角色 / 光锥图片、补金顺序与过渡档位，点分数还能展开刻度来源和相近的次选配队。
