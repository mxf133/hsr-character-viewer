角色总榜 角色 / 星魂 / 光锥混排 · 只看黑塔网投稿数据

这个榜完全不看你的角色池：每个副本先只保留判据最好的一档与次好的一档 （混沌回忆/虚构叙事是 0T / ≤2T、末日幻影是 积分 4000 / ≥3700、异相仲裁·绝境王棋关是行动值 <300 / <500）， 这批投稿全部进池（v4.6.78 起不再只圈最便宜的 25%）， 最后看每个单位在这批里出现的占比—— 占比越高说明它越常在能出分的阵容里出现。

下面的 E0 / E1 / E2 / E6 是把这一份榜拆成四个星魂档： 每一档各自比较，一个角色在每个档位都可能有自己的一行 （取它抽到这一档时最强的那个整包）。所以「最佳成绩在 E2」的角色， 切到 E0 也能看到它 E0 档的分数与名次 —— 不会因为别的档位分更高就消失。

权重 两大类：关卡权重决定 哪些副本算数（角色总榜与抽卡方案都吃它，调成 0 = 这个副本不进榜）； 抽卡权重决定角色总榜与抽卡方案里强度 / 性价比 / 泛用性 各占多少（强度越高越推行动值低、投入高的强队， 性价比越高越推你还要补得越少的队伍）。两组都只有相对大小有意义。

抽卡方案

这里给你的是可以照着走的补金路线：先看你已有几位核心角色， 再看下一步最适合补什么。候选来自角色总榜里的真实队伍， 同一支队伍只留一条；补金推荐分 = 强度得分 × 抽卡权重 + 差额接近度 × 抽卡权重， 「强度」那一档看的是角色总榜那一列的强度分（绝对 0~100，与总榜同一个数）—— 每个副本取最少行动值那一次成绩、按关卡权重加权，再按投入档位补分， 所以行动值越低越高、投入越高越高（E6S5 > E6S1 > E2S1 > E0S0）， 与金数无关； 「性价比」那一档看的是你自己还要补几金 （差额接近度 = (1 − 补金 ÷ 候选池封顶值)^1.5 —— 指数让要补十几金的队伍掉得更快， 补 1~2 金的几乎不受影响）。 两档一个是「这支队打得多好」、一个是「你要补几金」，各管一头。 每张卡都带角色 / 光锥图片、补金顺序与过渡档位， 点分数还能展开刻度来源和相近的次选配队。
