# 抽卡方案 · 虚拟账号可行性实测

工具版本 **v4.6.92**｜数据集：77 条角色总榜整包｜隐金设置：不勾

抽卡权重：强度 50% / 性价比 50%｜② 曲线指数 1.5｜展示上限 6 条（本报告用全池算分）

**为什么要造虚拟账号**：抽卡方案的两档分别来自两个源头 —— ① 强度来自**数据集**里的真实玩家投稿（黑塔网），② 差额来自**你自己的账号**（拥有哪些角色 / 星魂 / 光锥）。所以只要有真实数据集，就能造出任意账号来测整条链路。这份报告里的账号全是虚拟的，但**强度那一档用的完全是真实数据**。

**怎么读这张表**：

- 「① 强度」= 该队伍在角色总榜上的整包分（含金数项）在**本账号候选池**里的位置 ——同为绝境 0T 时，金数越少这一档越高；
- 「② 差额接近度」= `(1 − 要补金数 ÷ 本池 p75)^1.5 × 100` —— 只跟你**缺什么**有关；
- 「补金」= 你要补几金，「账面」= 这支配置**总共**几金（不进分数，只作参考）；
- ⚠️ 两个刻度都是**按本账号的候选池现算**的，所以**不同账号之间的分数不可直接比较**（本报告里那个 ② 封顶值就随账号变：全新账号 19 金、老账号 14 金）。

**自己要复算 / 换设置**：

```bash
node tools/team-plan-cases.mjs --rows=6                      # 隐金默认按界面（五项全勾）
node tools/team-plan-cases.mjs --rows=6 --markdown=out.md    # 顺便写一份报告
node tools/team-plan-cases.mjs --account=1                   # 追加一条：本机第 1 个真实账号
```
