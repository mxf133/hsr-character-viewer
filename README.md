# 崩坏：星穹铁道 抽卡推荐计算器

用[黑塔网](https://theherta.com)的公开投稿数据 + 本机缓存的米游社角色快照，算出**角色总榜**与**补金推荐**：
谁值得补、补到几魂几叠、哪些队伍「同为 0T 但更省金」。

零第三方依赖、纯本地运行；打开页面与切换分页**都不联网**，只有你点「同步」才会抓数据。

> **下载**：最新便携包见 [Releases](https://github.com/mxf133/hsr-character-viewer/releases)（解压后双击 `start.bat` 即可，无需 `npm install`）。

![角色总榜](docs/screenshots/抽卡推荐-角色总榜.png)

## 它回答什么

- 我已有的角色里，**下一个金花在谁身上**最划算？（补金推荐分 + 每金收益）
- 同一份成绩下，**哪套阵容更省金**？（同为绝境 0T，9 金那支强于 16 金那支）
- 这个角色的**角色强度 / 角色性价比 / 角色泛用性**各是多少，**分数从哪来**？（逐关卡来源表，可逐行验算）

## 功能

| 页面 | 内容 |
| --- | --- |
| 抽卡推荐 | 角色总榜（77 个角色；总榜 + E0/E1/E2/E6 四个星魂档各自一条）、四个副本的关卡权重、补金方案与补金顺序、战斗记录（米游社官方四个副本的逐层队伍与积分） |
| 角色信息 | 角色面板：等级 / 星魂 / 光锥 / 遗器 / 行迹，支持「只看我没有的」筛选 |
| 得分来源 | 每个分数都能展开：逐关卡的权重 × 表现 × 金数 × 版本，以及三项来源（角色总榜里叫**角色强度 / 角色性价比 / 角色泛用性**，抽卡方案里叫**队伍强度 / 队伍性价比 / 队伍泛用性**） |
| 虚拟账号 | 9 种角色池预设（全新账号 / 单核起步 / 单推 / 双核主C …），用来试「从零开始抽什么」而不动你的账号 |
| 隐金设置 | 「累计赠送」「兑换角色 / 光锥」等按 0 成本参与总榜，更贴近你的真实投入 |

## 快速开始（Windows）

1. 装 [Node.js](https://nodejs.org) ≥ 18.17（无需 `npm install`，本项目零依赖）。
2. 双击 `start.bat`（等价于 `npm start`），浏览器会自动打开 <http://127.0.0.1:8360>。
3. 右上角**扫码登录**米游社（或手动粘贴 cookie）→ 点「同步黑塔网数据」。

> 登录凭证与角色快照只写本机 `data/`，该目录已在 `.gitignore` 中，**不会**进入版本库。
> 不登录也能看角色总榜；登录后才会标出「已有」，并据此计算补金方案。

## 数据来源与评分口径

- **强度数据**：黑塔网 theherta.com 的公开投稿（本机缓存 `theherta/archive.json`）。
- **角色面板**：米游社官方接口，扫码登录后抓取一次。
- **角色得分** = 角色强度 × 权重 + 角色性价比 × 权重 + 角色泛用性 × 权重（抽卡权重默认 **1 : 1 : 0.5**，可自己调）
  - **角色强度**：**只看行动值**（成本不影响这一列）。每个副本取该整包**最佳证据那支队自己**的行动值：**打出 0 行动值（绝境）/ 0T（轮次制）就是 100 分**，其余按判据线曲线折算、上限 90 分。一个整包的强度 = 各副本强度按**关卡权重**加权平均（缺副本按 0）。某个版本这一档**没有投稿**时，会**继承同角色更便宜的整包**在那一期的最高分（因为多数人不会拿满配去刷低难关卡）；连更便宜的版本也没有 → 那一版算 0 分。所以低难副本常常是满分，整包要拿 100 则要 5 个副本每一期都打出 0 行动值（当前数据里还没有）。
  - **角色性价比**：同一份成绩下，**金数越少越高**；最近 6 个版本按 3:2.5:2:1.5:1:0.5 加权（未上线版本不参与），详情里的「最佳证据」取**版本最新**的那一次。
  - **角色泛用性**：能通关的队伍里出现过的**不同队友数**，按关卡权重 × 版本权重加权（没投稿的版本计 0）。**E6 与 E6 比、E0/E1/E2 与 E0/E1/E2 比**（两把尺子各自归一，避免不同量级之间的比较）——旧版本的队友关系会被稀释，新登场角色只按它有成绩的版本算。
- 界面功能要求（可逐条验收的清单）见 [`docs/功能要求.md`](docs/功能要求.md)；
  每一轮口径变更的**理由**与实测数字见 [`docs/评分模型设计.md`](docs/评分模型设计.md)。

## 目录结构

```
bin/       启动与版本脚本（serve.mjs / version.mjs / open-when-ready.ps1）
src/       服务端：登录与签名、缓存策略、结论与评分计算
public/    前端：原生 ES 模块 + 手写 CSS，无构建步骤
tools/     数据抓取与构建、测试套件、探针
theherta/  黑塔网数据集（archive.json + 中英名称映射）
docs/      设计文档与截图
```

## 测试

```bash
node tools/run-tests.mjs          # 全部套件

```
